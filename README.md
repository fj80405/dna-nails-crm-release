# DNA nails 下載

安的DNA美甲基因庫（穿戴甲客戶、訂單管理），Android 8 以上的手機用。

## 下載最新版

👉 **[點這裡下載最新版](https://github.com/fj80405/dna-nails-crm-release/releases/latest/download/dna-nails-crm.apk)**

## 第一次安裝

1. 用手機打開上面的連結，下載 `.apk` 檔。
2. 下載完點那個檔案。
3. 手機說「不允許安裝不明來源的應用程式」時，按「設定」，打開「允許這個來源」，再按返回。
4. 按「安裝」（已經有舊版的會顯示「更新」），裝好按「開啟」。

## 之後更新

打開 App 時會自動檢查，有新版會跳出「有新版」，按「更新」，下載完再按一次「安裝」。客戶和訂單資料都會保留。
